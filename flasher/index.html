ARGUS

Anti-surveillance firmware for the LILYGO T-Watch Ultra. Flash it straight from this page over USB, no toolchain.

latest release
  1. Use desktop Chrome or Edge. Firefox and Safari cannot flash over WebSerial.
  2. Hold BOOT while connecting the watch with a USB-C data cable. This puts it in download mode. The browser cannot reset the watch out of the running app on its own, so this step is required, not a fallback.
  3. Click Install and pick the watch's serial port.
  4. If you are offered a full erase, decline it unless you want to lose your mode choice, Offense PIN and notification settings. Your SD card is never touched.

This browser does not support WebSerial. Open this page in desktop Chrome or Edge, or flash with esptool using the assets on the release page.

If the port does not appear or flashing stalls, hold BOOT while tapping RESET, then try again. This page installs the four firmware parts at their own offsets, which is exactly what the PlatformIO toolchain writes.

ARGUS is a fork of r3dfish's 13:37 firmware, MIT licensed. Source, releases and the SD-card assets: github.com/h4d35x0/argus. After flashing, copy the release's sdcard.zip to a FAT32 microSD card for the mode wallpapers.
