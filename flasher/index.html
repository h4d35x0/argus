ARGUS

Anti-surveillance firmware for the LILYGO T-Watch Ultra. Flash it straight from this page over USB, no toolchain.

latest release
  1. Use desktop Chrome or Edge. Firefox and Safari cannot flash over WebSerial.
  2. Connect the watch to this computer with a USB-C data cable.
  3. Click Install, pick the watch's serial port, and confirm the erase.

This browser does not support WebSerial. Open this page in desktop Chrome or Edge, or flash with esptool using the assets on the release page.

If the port does not appear or flashing stalls, hold BOOT while tapping RESET to force download mode, then try again.

ARGUS is a fork of r3dfish's 13:37 firmware, MIT licensed. Source, releases and the SD-card assets: github.com/h4d35x0/argus. After flashing, copy the release's sdcard.zip to a FAT32 microSD card for the mode wallpapers.
